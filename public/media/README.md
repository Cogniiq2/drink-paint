# Media

Every file in this folder is a **placeholder** generated by
`scripts/generate-placeholders.mjs`. Replace with real photography from the
preview event, keeping filenames and roughly the same aspect ratios:

| File                  | Use                              | Ratio  |
| --------------------- | -------------------------------- | ------ |
| hero-poster.webp      | Hero poster (LCP image)          | 16:10  |
| hero-poster-mobile.webp | Hero poster, portrait phones   | 2:3    |
| hero-film.mp4         | Silent hero film, ≤ 4 MB, H.264  | 16:9   |
| hero-film-mobile.mp4  | Portrait variant, ≤ 2.5 MB       | 9:16   |
| arrival.webp          | Gallery – doors / arrival        | 4:5    |
| wine-pour.webp        | Gallery – glass being poured     | 4:5    |
| brush-detail.webp     | Gallery – brush on canvas        | 10:7   |
| guests-painting.webp  | Gallery – hands painting         | 10:7   |
| table-wide.webp       | Wide shot of the full table      | 16:9   |
| finished-art.webp     | Finished canvases                | 4:5    |
| atelier-room.webp     | The room, empty, lit             | 3:2    |
| exterior-night.webp   | Schulstraße at night             | 10:7   |
| private-table.webp    | Private events hero              | 12:7   |
| gallery-01…06.webp    | Instagram-style editorial grid   | 1:1 / 4:5 |
| og-default.webp       | Default social preview           | 1200×630 |

Set `NEXT_PUBLIC_HERO_FILM_ENABLED=true` once the film exists.
